# Universal File Opener, Extractor & Converter

A desktop GUI utility built with Python and Tkinter for extracting compressed archives and converting file formats with ease.

## Features
- **Archive Extraction**: Supports ZIP, TAR, GZ, 7Z, RAR.
- **Format Conversion**:
  - Image to Image (PNG, JPG, WEBP, BMP, ICO)
  - Document conversion (DOCX -> PDF, TXT -> PDF)
  - Data conversion (CSV -> XLSX, XLSX -> CSV)
- **Drag & Drop UI**: Intuitive dark interface with live progress bars and large file handling (GB+).
- **Windows Integration**: Optional right-click context menu integration.

## Requirements
- Python 3.8+
- Dependencies: `pip install -r requirements.txt`

## How to Run
Double-click: `run.bat`
Or run via terminal:
```bash
python extractor.py
```
